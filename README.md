# .NET Learning Lab

A curated collection of my earlier C#/.NET learning projects. The original repositories were consolidated here so the source code is easier to browse while generated files and local artifacts stay out of version control.

## Contents

| Folder | Topics |
| --- | --- |
| `csharp-basics/` | C# syntax, collections, delegates, events, and small exercises |
| `linq/` | LINQ queries and data-processing practice |
| `games/1a2b-basic/` | Console-based 1A2B game |
| `games/1a2b-linq/` | 1A2B implementation using LINQ |
| `entity-framework/basic/` | Entity Framework fundamentals |
| `entity-framework/contact-demo/` | Contact-management data access demo |
| `entity-framework/homework/` | Entity Framework practice projects |

## Notes

- These are historical learning exercises and may target older .NET Framework versions.
- `.vs`, `bin`, `obj`, package caches, compiled binaries, and local database files were intentionally excluded.
- Each folder preserves the original project structure where practical.

## Why this repository exists

This repository documents my learning path in C# and .NET. For current portfolio projects, see my GitHub profile and pinned repositories.
